# Testes

- `logic.test.js`: testa as regras de validação, busca, exportação CSV, quantidade, estoque e total.
  Rode com `node tests/logic.test.js`.

Observação: o teste copia as funções para verificar a lógica. Ele não executa o site no navegador.
Para testes de interface, é preciso um navegador de verdade (por exemplo, Playwright), que não está disponível neste ambiente.
