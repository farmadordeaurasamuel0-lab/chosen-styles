# Chosen Styles

Loja de camisetas cristãs com estética streetwear premium.

## Estrutura do repositório
- `frontend/`: site da loja (HTML, CSS e JavaScript gerados por `build.mjs`). Pasta a ser publicada no Vercel.
- `backend/`: banco de dados Supabase (migrações e regras de acesso). Ainda não conectado.

## Começar
```
cd frontend
npm run build   # gera dist/index.html
npm test        # testa as regras de validação
```

Para publicar, veja `frontend/README.md`.
